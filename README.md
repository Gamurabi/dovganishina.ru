# Сайт «Марина Довганишина — репетитор по английскому для школьников»

Статический сайт: никаких сборщиков и баз данных. Достаточно загрузить папку
на любой хостинг (Timeweb, Beget, reg.ru, GitHub Pages, Netlify и т. п.).

## Структура

```
index.html         главная
obrazovanie.html   образование и документы (с увеличением сканов)
ceny.html          прайс-лист
kontakty.html      контакты и что написать при записи
css/style.css      все стили
js/contacts.js     КОНТАКТЫ — единственное место, где их нужно менять
js/main.js         мобильное меню, подстановка контактов, лайтбокс
img/photo.jpg      фото для главной
img/docs/          сканы документов в полном размере
img/thumbs/        миниатюры сканов
```

## Что нужно заполнить

1. **Контакты** — откройте `js/contacts.js` и впишите реальные ссылки на
   Telegram, WhatsApp, Max, почту и телефон. Пустая строка скрывает кнопку.
2. **Видеовизитка** — в `index.html` найдите комментарий «КАК ВСТАВИТЬ РОЛИК»
   и замените заглушку на `<video>` с файлом или `<iframe>` с YouTube / RuTube / VK.
3. **Скан НИИДПО** — положите изображение в `img/docs/`, миниатюру в `img/thumbs/`
   и оформите карточку в `obrazovanie.html` по образцу соседних.
4. **Реквизиты** в футере — при необходимости добавьте строку с ИНН
   (место отмечено комментарием в `index.html`).
5. **Фото** — текущее 320×427 px. Если есть оригинал крупнее, замените
   `img/photo.jpg` на него (желательно от 600 px по ширине).

## Как посмотреть локально

Откройте `index.html` двойным кликом или запустите из папки сайта:

```
python3 -m http.server 8765
```

и перейдите на http://localhost:8765
